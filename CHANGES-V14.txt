Codenames Bilingual V14
=======================

V14 keeps the V13 game engine and card behavior, and redesigns the online pre-game lobby around the supplied Codenames-style UI specification.

Main changes
------------
- New dark three-column Room Lobby: Blue Team / Game Settings / Red Team.
- Spectators are centered above the lobby with circular avatar thumbnails, nicknames, host crown, online/offline state, and realtime movement between sections.
- Every new room member starts as a Spectator by default.
- Functional JOIN TEAM buttons for Blue/Red Operative and Blue/Red Spymaster.
- One Spymaster slot per team is enforced in the UI; an occupied slot is disabled for other players.
- Host-only START GAME validation: 4+ active players, 2+ per team, exactly one Spymaster per team.
- Host Reset teams returns everyone to Spectators.
- Host Randomize teams distributes everybody between Red/Blue as Operatives; Spymasters are then selected manually.
- New room-level Lock teams setting, synchronized through Firebase.
- New top navigation: Admin, News, Rules, Settings.
- New Settings modal with Admin / Player / Preferences / Accessibility tabs.
- Player settings: nickname, avatar, self-assignment, Spectator, Leave Match.
- Preferences: UI language, dark mode, sound preferences, always-show guess cue, hide room URL, reset tutorial hints.
- Accessibility: text size, colorblind symbols, static background, reduced-motion mode, gameplay animation disable option.
- Contextual Quick Guide with GOT IT, RULES, close, and Auto-show behavior.
- Rules and News dialogs are non-destructive overlays and do not change match state.
- Room URL can be hidden locally without losing the ability to copy the invitation URL.
- Firebase rules updated so players can safely change only their own permitted lobby fields while teams are unlocked.
- Existing V13 card reveal behavior and classic Codenames game rules remain unchanged.

Important Firebase migration
----------------------------
V14 changes firebase-rules.json. If the game is already deployed, publish the V14 database rules before testing self-service JOIN TEAM / avatar changes / team locking.
