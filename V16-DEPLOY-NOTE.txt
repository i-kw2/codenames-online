V16 DEPLOY NOTE — REQUIRED FOR INVITE FIX
=========================================

1. Upload/replace ALL files from V16 on your hosting site.
2. Keep your existing real values in js/firebase-config.js.
3. Firebase Console -> Realtime Database -> Rules.
4. Replace the current rules with the complete contents of V16 firebase-rules.json.
5. Press Publish.
6. Make sure Firebase Authentication -> Sign-in method -> Anonymous is enabled.
7. Open the deployed site in a normal window and create a room.
8. Copy the Invite Link and open it in Incognito/private browsing.
9. Confirm the screen says exactly:
   Welcome to Codenames
   To enter the room, choose a nickname.
   Nickname
   ENTER GAME
10. Enter a nickname. The new player should enter as Spectator.
11. Start the game from the Host.
12. Open the same Invite Link in a NEW private session/device.
13. Enter a nickname again. The player should still be allowed into the running match.
14. Settings -> Player should open automatically; choose Blue/Red Operative or an available Spymaster slot.

If step 10 or 13 returns permission_denied, the most common cause is that V16 firebase-rules.json was not published, or Anonymous Authentication is disabled.
