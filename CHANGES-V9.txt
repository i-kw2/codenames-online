V9 requested changes
====================

1) Center-screen turn notifications
- A large centered overlay announces Red Team Turn / Blue Team Turn.
- Wrong neutral/opponent guesses show a wrong-choice animation, then animate the color handoff to the next team.
- Added matching Web Audio sound effects.
- Respects prefers-reduced-motion and the existing mute/volume controls.
- Late joiners do not replay every historical turn animation.

2) Host-only Reset Round / New Game (online)
- Non-host players do not see these two buttons.
- UI refuses to send these actions for non-hosts.
- Online action layer refuses them for non-hosts.
- Firebase rules file additionally restricts resetRound/returnLobby to the host.
- Existing host-side authoritative action authorization remains in place.

3) Automatic Spymaster key (online)
- Online Spymasters automatically enter Spymaster View as soon as the secret map is available.
- No Spymaster Key button or hold-to-reveal interaction is shown online.
- Spymasters remain in secret view after clue submission/challenge/penalty transitions.
- Operatives still never render unrevealed secret roles.
- Local shared-device privacy behavior is preserved because local mode cannot know which person is physically holding the device.

Validation performed
- JavaScript syntax checks passed for modified core files and online ES module.
- firebase-rules.json parses as valid JSON.
- Existing game logic suite: 31/31 tests passed in a Node harness.
