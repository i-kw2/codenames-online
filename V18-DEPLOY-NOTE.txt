V18 DEPLOY NOTE
===============

V18 is an in-game UI/animation/log upgrade built on the stable V17 online flow.

IMPORTANT:
1. Upload/replace the full V18 site files, not only index.html.
2. Keep your real Firebase values in js/firebase-config.js. The V18 package intentionally keeps the same file bytes as V17.
3. V18 does NOT introduce a new Firebase Realtime Database rule schema. firebase-rules.json is byte-for-byte identical to V17.
   - If V17 joining already works, you do not need a new rules migration specifically for V18.
   - Do not roll back your already-working V17 rules.
4. The URLs in index.html use ?v=18.0 cache-busting. After deployment, hard-refresh once or test in a private window.
5. Test with at least two browsers/devices:
   - Host + guest enter the same room.
   - Start game: both should see the 25-card deal.
   - Current Spymaster submits a clue: both should see the same centered clue announcement.
   - Current Operative guesses a card: both should see the Game Log update.
   - Switch turns and confirm the next clue/guess is appended rather than replacing history.

No Firebase Rules change is required solely for the four V18 features.
