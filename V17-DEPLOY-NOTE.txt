V17 INVITE JOIN FIX — IMPORTANT DEPLOYMENT STEPS

1) Upload the V17 site files.
2) KEEP your real js/firebase-config.js values. Do not replace them with placeholders.
3) Firebase Console -> Authentication -> Sign-in method -> Anonymous -> ENABLE.
4) Firebase Console -> Realtime Database -> Rules.
5) Replace the old rules with V17 firebase-rules.json and press PUBLISH.
6) Firebase Console -> App Check -> Realtime Database:
   - If Enforcement is OFF: no extra App Check setup is required for this project.
   - If Enforcement is ON: configure Web App Check in the site, or turn enforcement OFF while testing.
7) Create a NEW room after publishing V17 rules.
8) Open its invite link in a private/incognito window or a second device.
9) Enter a nickname -> ENTER GAME.

V17 also has a Lobby-only compatibility fallback for old V13 rules. However,
joining AFTER a game has started requires the V17 server rules because old V13
rules explicitly reject creation of new players while status=playing.
